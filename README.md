# Fundamentos de Next.js e React com TypeScript

Projeto de estudo para praticar a estrutura de uma aplicação Next.js com React e TypeScript, incluindo páginas e componentes.

## Stack
- Next.js
- React
- TypeScript

## Como executar

```bash
npm install
npm run dev
```

Acesse http://localhost:3000. Para compilar, use `npm run build`.
